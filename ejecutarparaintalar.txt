=== INSTALACION EN UN PC NUEVO ===

1) Clonar/copiar el proyecto (sin .venv, se recrea abajo)
   git clone <url-del-repo>
   cd <carpeta-del-proyecto>

2) Copiar el archivo .env a la raiz del proyecto (NO viene en git, hay que llevarlo aparte)
   Debe contener:
   SUPABASE_URL=
   SUPABASE_KEY=
   SUPABASE_SERVICE_ROLE_KEY=

3) Instalar Python 3.14 (misma version usada en .venv/pyvenv.cfg) si no esta instalado

4) Crear entorno virtual e instalar dependencias
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt

=== CORRER EL PROYECTO (cada vez) ===

.\.venv\Scripts\Activate.ps1
uvicorn main:app --reload --port 8000

Luego abrir: http://127.0.0.1:8000/login
